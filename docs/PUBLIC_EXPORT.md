# 公開版の収録範囲

公開元は `Daiki-Hashimoto-NAIST/InstantMuscle` の `main`、取得時のコミットは `ae513ef143eee87c67bb4819c41f9f86a59fa49f` です。公開版は新しい履歴で作成しており、元リポジトリのコミット履歴、Issue、PRは含みません。

## 保持したもの

ゲームのC#コード、EditModeテスト、Editorツール、シェーダー、メインシーン、設定、Prefab、設計資料を保持しています。素材を参照するシーンやPrefabのGUIDは書き換えていません。参照先の素材がない箇所は、Unity上でMissingになることがあります。

## 除外したもの

| 分類 | 対象と理由 |
| --- | --- |
| アバター・モデル・テクスチャ | 取得素材の元データの再配布条件を確認できないため |
| Mixamoアニメーション | 同梱READMEに元FBXの公開を禁止する記載があるため |
| 音源・掛け声・画像素材 | 元データの再配布条件を確認できないため |
| SDKサンプル・TextMesh Pro素材 | 提供元から別途取得する構成にしたため |
| Unityテンプレート・試作シーン | `TutorialInfo`、`Readme.asset`、`SampleScene`、`TestArima` |
| 開発環境の補助ファイル | AIエージェント設定、引き継ぎメモ、IDE設定、開発キャプチャなど |

元リポジトリの追跡対象1,551ファイルから1,064ファイルを除外しました。個別のパスと理由は [OMITTED_FILES.csv](OMITTED_FILES.csv) に記録しています。素材の除外は「未使用」と判定した結果ではありません。実行に使われる素材も含みます。

Unityキャッシュやビルド出力は元リポジトリの追跡対象に含まれていません。動的生成やコードからの利用を確認せずに、ゲームのC#コードを未使用と判断して削除する処理は行っていません。

## 設定の変更

開発用の `com.coplaydev.unity-mcp` と `io.github.hatayama.uloopmcp` をmanifestとlockfileから削除しました。Unity Cloudのプロジェクト・組織への紐付けを空にし、公開版の素材やローカル設定が意図せず追加されないよう `.gitignore` を更新しました。バイナリ素材の大半を除いたため、元のGit LFS設定は引き継いでいません。

## 復元時の注意

1. Unity `6000.3.10f1` で開き、Package Managerで依存関係を取得します。
2. 使用しているMeta Movement SDKなどのサンプルとTextMesh Proの必要素材を提供元から取得します。SDKサンプルのコードを参照する部分では、取得までコンパイルエラーが出る可能性があります。
3. アバター、BlendShape、Humanoidアニメーション、音源、画像などを利用条件に従って用意します。代替素材を使う場合は、ボーンやBlendShape名も実装・設定と合わせます。
4. `Assets/Scenes/InstantMuscle_proto.unity` とPrefabのMissing参照を修復します。素材の再取得だけで元のGUIDが復元されるとは限りません。
5. EditModeテストを実行し、Quest上の入力、描画、追跡の復帰を別途確認します。ハードウェア連携の設定と旧資料には差異があるため、コードと実機構成の照合が必要です。

この手順は復元時の確認事項を示すもので、公開版で完了を確認した起動手順ではありません。
